`main.ts` (Node 22, stdlib only) writes a single museum placard line for an ordinary office stapler, labelled as if it were an ancient artifact — 139 characters, one line — to `/output/entry.txt`:

> Stapler, c. 2019, steel and quiet resentment. Donated by Accounts, who bound thirty years of expense claims with it; not one was ever read.

Run it with:

```sh
node main.ts
```
